# JARVIS Helper (Mac)
1. Render → Environment me `JARVIS_HELPER_TOKEN` = koi lamba random text (16+ akshar) → Save.
2. Mac: Node.js 18+ chahiye. Terminal me:
   ```
   cd helper && npm install
   export JARVIS_HELPER_TOKEN="wahi-token"
   npm run login -- <recipe-naam>     # ek baar, khud login
   npm start                          # chalta rahe
   ```
3. Dashboard JARVIS me bolo: "<portal> se report download karo". `tasks dikhao` se status.
Reports `~/JARVIS-Reports` me aati hain. Naye portal ke liye `recipes/_example.json` copy karke selectors badlo.
