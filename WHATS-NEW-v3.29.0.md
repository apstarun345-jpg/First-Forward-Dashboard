# 🎉 What's New — v3.29.0

> **Approve kiya, print kiya, dispatch karo** — employee link se aayi request (full address + pincode ke
> saath) ab seedha A4 label me print hoti hai; company ka FROM address Settings me likh do, text size
> bhi badha-ghata sakte ho.

## 1) 🖨️ Dispatch label — Print / PDF / Share / Copy (request drawer me)

🏷️ Tag Requests → koi bhi **employee link wali request kholo** (jisme delivery address hai) →
"🖨️ Dispatch label" section:

- **🖨️ Print / 📄 PDF** — ek click me naya print page khulta hai (A4):
  - Ek hi address **left + right dono taraf** repeat hota hai (2 columns) aur pure page pe (8 / 10 / 12 copies —
    "Per page" select se)
  - Har label me: **FROM** (company), **TO** (employee name, mobile, address, **bada PIN code**),
    Request ID, date, total tags
  - Print page par bhi **text size buttons (A− / A / A+ / A++)** — chhota ya bada karke print karo
  - Print dialog me **"Save as PDF"** chuno → PDF ban jaati hai, jo dispatch team ko WhatsApp/email par
    bheji ja sakti hai — wo ussi se dobara print karegi
- **📄 PDF / Share** button ke aage **Text size** aur **Per page** selectors bhi drawer me hi hain
- **📋 Copy label** — FROM + TO + request summary ka plain text (WhatsApp/Excel me paste karne ke liye)
- Approved hone pe section ke upar "✅ approved — ab print karo" dikhta hai; pending pe hint milta hai

## 2) ⚙️ Settings → 📲 Contacts — company ka FROM address (ek baar likho)

- Settings → Contacts & sharing → naya card: **🖨️ Dispatch label — FROM (company ka address)**
- 3 fields: **Company naam**, **Company ka poora address** (multi-line), **Company phone** — SAVE karo
- Ye **har dispatch label par FROM block** ke roop me dikhta hai (naam blank chhodo to app ka brand use hota hai)
- Drawer me agar FROM nahi bhara ho to amber warning aati hai — ek baar Settings me bharo, sab labels ready

## 3) 🖨️ Request save karne ke baad workflow

1. Employee link se request aayi (naam + mobile + address + pincode) → admin ke bell notification
2. Admin request khata hai → **Status ✅ approved** → Save
3. Ussi drawer ke 🖨️ section se **Print / PDF** → print karke dispatch team ko de do
4. Dispatch team us print ko dekh kar packets par label chipkayegi (left+right same address) ya PDF se dobara print karegi
