# v3.124.9 — Personal Link Activity Calendar

- Personal links with issuance access get a responsive **Activity Calendar** tab. The calendar shows daily issuance for the link's agent or team in the current and previous month, using the same scoped data as Date-wise Issuance.
- Tap a completed day to see VC4, VC20 and VC5+ counts. Future dates and today are unavailable because the underlying completed report ends yesterday; Today Live remains separate.
- The calendar respects the link's issuance permission and channel switch, and it shows a data-delay note. Empty days are labelled as no issuance recorded, not proof of a complete source sheet.
